# Quick Start Guide - No API Required

## Get Started in 5 Minutes!

This extension works perfectly **without any SaberSim API**. Follow these simple steps:

### Step 1: Export Player Pool (30 seconds)

Go to DraftKings or FanDuel:

**DraftKings:**
1. Open any contest
2. Click "Download Players List"
3. Save the CSV file

**FanDuel:**
1. Navigate to contest
2. Click "Export" button
3. Save the CSV

### Step 2: Import to Extension (10 seconds)

1. Click the extension icon
2. Make sure "Import CSV" mode is selected (default)
3. Click "Choose File" under "Import Player Pool"
4. Select your CSV file
5. Click "Import Players"

You'll see: "✓ Imported 250 players from DraftKings"

### Step 3: Configure Settings (1 minute)

1. **Select Sport**: Choose from dropdown (NFL, NBA, MLB, etc.)
2. **Contest Type**: Classic, Showdown, etc.
3. **DFS Site**: DraftKings or FanDuel
4. **Build Parameters**:
   - Number of Lineups: 1-150
   - Salary Cap: Auto-filled
   - Exposure: Set max/min percentages
   - Stacking: Enable for QB+WR combos

### Step 4: Optimize! (5 seconds)

1. Click the big green "Optimize Lineups" button
2. Wait 2-5 seconds
3. View your optimized lineups!

### Step 5: Export & Upload (30 seconds)

1. Review generated lineups
2. Click "Export to CSV"
3. Go back to DraftKings/FanDuel
4. Click "Upload Lineups"
5. Select the exported file
6. Done!

## Total Time: ~5 Minutes

## FAQ

**Q: Do I need a SaberSim subscription?**
A: No! This works with just the DFS site exports.

**Q: Will the lineups be good?**
A: Yes! The local optimizer uses value-based optimization with stacking and exposure controls.

**Q: How many lineups can I generate?**
A: Up to 150 lineups in just a few seconds.

**Q: What if I want better projections?**
A: You can:
- Use DFS site projections (included in CSV)
- Subscribe to FantasyPros, RotoGrinders, etc.
- Build your own projection model
- Add custom projections manually

**Q: Does this work offline?**
A: Almost! You need internet to load the extension, but optimization runs locally in your browser.

**Q: Which sports are supported?**
A: All of them! NFL, NBA, MLB, NHL, PGA, Soccer, NASCAR, MMA, College sports.

## Tips for Better Lineups

### Use Good Projections
- DFS site projections are okay
- Paid projection services are better (FantasyPros, RotoGrinders)
- Your own models can be best

### Enable Stacking
- NFL: QB + 2-3 pass catchers from same team
- NBA: Stars from same team
- MLB: Hitters from same batting order

### Adjust Exposure
- **Tournaments (GPP)**: Lower max exposure (30-50%) for uniqueness
- **Cash Games**: Higher min exposure (80-100%) for your top plays

### Generate Multiple Lineups
- Cash: 1-3 lineups
- GPP: 10-150 lineups for coverage

### Use Randomness
- Enable for tournament entries
- Creates diverse lineups
- Avoids "chalky" builds

## Troubleshooting

**"No players found"**
- Make sure CSV is from DraftKings or FanDuel
- Check file isn't corrupted
- Try re-downloading from DFS site

**"Invalid salary"**
- Player pool might be missing salary data
- Re-export from DFS site

**"No eligible players for position"**
- Check sport/contest type match your CSV
- Verify position requirements

**Lineups look weird**
- Try disabling randomness
- Adjust exposure settings
- Check your projections are reasonable
