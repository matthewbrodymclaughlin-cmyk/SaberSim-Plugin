# Extension Icons

This directory should contain the Chrome extension icons in the following sizes:

## Required Icons

1. **icon16.png** - 16x16 pixels
   - Used in the Chrome toolbar
   - Should be simple and recognizable at small size

2. **icon48.png** - 48x48 pixels
   - Used in the Chrome extensions management page
   - Medium detail level

3. **icon128.png** - 128x128 pixels
   - Used in the Chrome Web Store
   - Can include more detail

## Design Guidelines

- Use a consistent design across all sizes
- Keep the design simple and recognizable
- Use colors that stand out but aren't too bright
- Consider the SaberSim brand if applicable
- Recommended colors: Purple/blue gradient (matching the extension theme)

## Creating Icons

You can create these icons using:

1. **Design Tools**:
   - Figma (free, web-based)
   - Adobe Illustrator or Photoshop
   - Canva (free, web-based)
   - GIMP (free, open-source)

2. **Icon Generators**:
   - Chrome Extension Icon Generator
   - Favicon.io
   - RealFaviconGenerator

3. **AI Tools**:
   - DALL-E, Midjourney, or Stable Diffusion
   - Prompt example: "Modern minimalist icon for a sports analytics app, purple and blue gradient, simple geometric shapes"

## Icon Suggestions

For a DFS optimizer extension, consider using:
- A bar chart or graph symbol (representing optimization/analytics)
- A sports ball (football, basketball, etc.)
- A trophy or star (representing winning)
- Dollar sign or coins (representing DFS contests)
- Abstract geometric shapes with sports theme

## Temporary Placeholder

Until you create custom icons, you can use a simple placeholder:

1. Create a solid color square image in your favorite image editor
2. Export in PNG format at the required sizes
3. Place them in this directory
4. Update with proper icons before publishing

## Example Icon Design

For the SaberSim DFS Optimizer, a good icon might feature:
- Background: Purple to blue gradient
- Symbol: Upward trending line graph or bar chart
- Accent: Small sports element (ball, helmet, etc.)
- Style: Modern, flat design

## File Naming

Keep the exact filenames:
- icon16.png
- icon48.png
- icon128.png

These are referenced in the manifest.json file.
